
# 📘 Technical Specification: Amy Hotel Booking System

**Project:** Amy Hotel Booking Web App
**Role:** Senior Full-stack Developer / System Architect
**Tech Stack:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Directus (Headless CMS), Zustand.
**Database Schema Version:** v7.0 (Final)

-----

## I. System Architecture Overview

We will adopt a **Layered Architecture** to ensure separation of concerns. The Frontend should not communicate directly with the Database or raw API calls in UI components.

[Image of Layered Software Architecture diagram]

1.  **Presentation Layer (UI):** Next.js Server/Client Components, Tailwind CSS.
2.  **State Management Layer:** Zustand (Global Client State for Booking Session).
3.  **Service Layer (Logic):** Abstraction layer handling API calls, error handling, and data transformation.
4.  **Domain Layer (Types):** TypeScript definitions matching Directus Schema v7.0.
5.  **Infrastructure Layer:** Directus SDK (Singleton Instance).

-----

## II. Level 1: Directory Structure Standardization

We strictly avoid the default "flat" structure. We use a **Feature-based** and **Domain-driven** folder structure suitable for enterprise scaling.

```text

│   ├── ui/                   # Atomic Design (Button, Input, Card - Reusable)
│   ├── modules/              # Business Logic Components (BookingForm, RoomCard)

├── lib/                      # Core Utilities & Config

│   ├── utils.ts              # CN (Classnames), Formatters
```

## III. Level 2: Domain Modeling (Type Definitions)

**File:** `src/types/schema.d.ts`
*Standardizing the contract between Backend (Directus) and Frontend.*

```typescript
// 1. Enums: Standardize status values to prevent "magic strings"
export enum BookingStatus {
  PENDING = 'pending',
  CONFIRMED = 'confirmed',
  CANCELLED = 'cancelled',
  COMPLETED = 'completed',
}

export enum DataStatus {
  PUBLISHED = 'published',
  DRAFT = 'draft',
  ARCHIVED = 'archived',
}

// 2. Base Entity: Fields automatically generated by Directus
export interface BaseEntity {
  date_created: string; // ISO 8601 String
  date_updated?: string;
  sort?: number;
}

// 3. File Interface (Directus Assets)
export interface DirectusFile {
  id: string;
  filename_disk: string;
  width?: number;
  height?: number;
  title?: string;
  url?: string; // Computed field
}

// 4. Domain Interfaces (Mapped 1:1 with Schema v7.0)

export interface Branch extends BaseEntity {
  id: number;
  status: DataStatus;
  name: string;
  slug: string;
  address: string;
  phone: string;
  map_url?: string;
  images: string[] | DirectusFile[]; // Union type to handle expansion
  description?: string; // HTML format
}

export interface RoomType extends BaseEntity {
  id: number;
  status: DataStatus;
  name: string;
  slug: string;
  price_base: number;
  inventory_count: number; // Core logic for availability
  capacity_adults: number;
  capacity_children: number;
  description?: string;
  branch_id: number | Branch;
}

export interface Booking extends BaseEntity {
  id: number;
  status: BookingStatus;
  customer_name: string;
  customer_phone: string;
  customer_email?: string;
  check_in: string; // YYYY-MM-DD
  check_out: string; // YYYY-MM-DD
  total_price: number;
  note?: string;
  items?: BookingItem[];
}

export interface BookingItem extends BaseEntity {
  id: number;
  status: DataStatus;
  booking_id: number | Booking;
  room_type_id: number | RoomType;
  quantity: number;
  price_snapshot: number; // Snapshot price at time of booking
}
```

## V. Level 4: State Management (Zustand)

Standardize the Booking Flow data persistence.

**File:** `src/store/use-booking-store.ts`

```typescript
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';

interface BookingState {
  // Search Context (User Input)
  dateRange: { from: Date | undefined; to: Date | undefined };
  guests: { adults: number; children: number };
  selectedBranchId: number | null;

  // Cart Context (Selection)
  cart: {
    roomTypeId: number;
    roomName: string;
    quantity: number;
    price: number;
  }[];

  // Actions
  setDateRange: (range: { from: Date | undefined; to: Date | undefined }) => void;
  addToCart: (item: any) => void;
  removeFromCart: (id: number) => void;
  clearCart: () => void;
  
  // Computed
  getTotalPrice: () => number;
}

export const useBookingStore = create<BookingState>()(
  persist(
    (set, get) => ({
      dateRange: { from: undefined, to: undefined },
      guests: { adults: 1, children: 0 },
      selectedBranchId: null,
      cart: [],

      setDateRange: (range) => set({ dateRange: range }),
      
      addToCart: (item) => set((state) => {
         // Logic to add or update quantity
         return { cart: [...state.cart, item] };
      }),
      
      removeFromCart: (id) => set((state) => ({
        cart: state.cart.filter(i => i.roomTypeId !== id)
      })),
      
      clearCart: () => set({ cart: [] }),
      
      getTotalPrice: () => {
        return get().cart.reduce((total, item) => total + (item.price * item.quantity), 0);
      }
    }),
    {
      name: 'amy-booking-storage', // Key in LocalStorage
      storage: createJSONStorage(() => localStorage),
    }
  )
);
```
